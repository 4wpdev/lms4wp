# AGENTS.md — правила для агентів у `lms4wp`

Робоча директорія: `/Users/admin/Projects/4wpdev/lms4wp`. Репозиторій приватний.
Основа — правила `4wp-mcp-connector/AGENTS.md`.

## Спілкування з автором

- Українською, на «ви». Коротко, чітко, без повторів.
- Лише те, що просять. Не вигадувати. Неперевірене позначати **(уточнити)**.
- Спершу перевірити (код, хаб, локальний сайт), потім питати. Не питати того, що є в проєкті або визначається логікою предметної області.

## Зміни лише з дозволу

- Редагувати, створювати чи переписувати файли — **лише** коли автор явно попросив. Аналіз і пропозиції — без запису.
- Старт робіт — **лише** після явного «виконайте». Перед цим — перелік файлів (створити / змінити / видалити) і команд, що змінюють систему.
- «Так» / «погоджуюсь» — не дозвіл на запис.
- «Виконайте» діє лише на погоджений перелік. Поза ним — новий перелік і нове «виконайте».
- Перед зміною — прочитати актуальний файл з диска. Файл на диску важливіший за пам'ять чату.

## Лише з дозволу автора

- `git commit`, `push`, гілки, теги, релізи — лише за чіткою вказівкою **і** повторним підтвердженням.
- Видалення файлів, нові залежності (Composer, npm).
- Зміна прийнятих рішень у `docs/decisions/` — нове рішення = новий ADR.
- Дії поза цією директорією: хаб, інші плагіни 4wp-*, тема, копія плагіна на локальному сайті, запис у його базу.

## Середовища

- Робота — лише на локалі `https://4wpdev.local/`. Прод `https://4wp.dev/` — лише для посилань.
- Сайт — Bedrock: `~/Local Sites/4wpdev/app/4wp.dev` (`public` → `4wp.dev/web`). Плагіни 4wp-* і lms4wp — симлінки `web/app/plugins/*` → `~/Projects/4wpdev/*`. Код у репо = код на сайті.
- `~/Local Sites/4wpdev/app/public-local` — окрема стара інсталяція з тією ж базою; сайт її не обслуговує. Для WP-CLI не використовувати.
- Залежності lms4wp: `composer install --no-dev` (Action Scheduler у `vendor/`, у `.gitignore`).
- WP-CLI — з `app/4wp.dev` (є `wp-cli.yml`): `php -d memory_limit=512M -d mysqli.default_socket="$HOME/Library/Application Support/Local/run/<site-id>/mysql/mysqld.sock" $(which wp) …` (сайт має бути запущений у Local).
- Контент — у хабі `~/4wp-publish-hub/LMS4WP/`. Хаб — джерело істини; на сайт контент лише імпортується.

## Джерела істини (по порядку)

1. `docs/decisions/` — прийняті рішення.
2. `docs/SPEC.md`, `docs/COURSE-FORMAT.md`, `docs/SITE-MAP.md`.
3. Офіційне: WordPress core (Abilities API, MCP Adapter).
4. `ARCHITECTURE.md`, `ROADMAP.md` — образ бажаного, не догма.

## Код

- Namespace `ForWP\LMS\`, файли в `includes/` (PSR-4), підключення — через `Core/Loader.php`.
- Text domain `lms4wp`. Мета-ключі `_lms4wp_*`. CPT `lms_*`.
- Стиль — як у наявному коді. Рядки UI — через i18n, вивід — escaping, ввід — sanitizing, форми — nonce.
