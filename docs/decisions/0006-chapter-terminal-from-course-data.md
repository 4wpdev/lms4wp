# 0006. Термінал уроку — з даних чаптера курсу
Дата: 2026-11-14 · Статус: Прийнято

## Контекст
Профіль терміналу 4wp-advanced-code на кожен урок дробить контент і його неможливо контролювати. Практика має бути прив'язана до чаптера, як FAQ.

## Рішення
1. У кожному модулі хабу — один `terminal.json`: команди чаптера (формат профілю 4wp-advanced-code) + `lessons` — привітання й команди кожного уроку.
2. Імпорт кладе його в мета курсу `_lms4wp_terminals[<module-key>]`; `verify` звіряє.
3. В уроці — лише тег практики: порожній ```` ```terminal ```` → блок `lms4wp/lesson-terminal`.
4. Блок знає урок → курс → чаптер і рендерить `forwp-advanced-code/terminal` з профілем `lms4wp-lesson-<ID>`.
5. 4wp-advanced-code має два універсальні фільтри: `forwp_ac_terminal_profile_data` (дані профілю замість JSON-файлу) і `forwp_ac_terminal_title` (назва в шапці). LMS4WP їх обслуговує; advanced-code про LMS не знає.
6. Код-блоки в уроках — завжди з явною мовою (`language` у `core/code`); без мови — `plaintext`. Автовизначення не використовуємо: воно помиляється (git-команди як SQL).

## Наслідки
- Без LMS4WP advanced-code працює як раніше.
- Профіль уроку віддається публічним REST лише для опублікованих уроків (або тим, хто може їх читати).
- Сайдбар терміналу: «This lesson» — команди уроку, «Chapter» — решта команд модуля; працюють усі команди чаптера.
