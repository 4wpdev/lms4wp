# 0004. Модуль — метадані курсу, не окремий CPT
Дата: 2026-11-14 · Статус: Замінено ADR-0008

## Контекст
У хабі курс складається з модулів, модуль — з уроків. Окремої сутності «модуль» у LMS4WP немає. Модуль не має власної сторінки — це група уроків у навігації.

## Рішення
- Курс зберігає список модулів у мета `_lms4wp_modules` (ключ, номер, назва, мета модуля).
- Урок зберігає ключ свого модуля в `_lms4wp_module`.

## Наслідки
- Без нового CPT і без нових таблиць.
- Якщо модулю знадобиться сторінка чи доступ — новий ADR.
