# 0002. WooCommerce не обов'язковий
Дата: 2026-11-14 · Статус: Прийнято

## Контекст
`ARCHITECTURE.md` описує WooCommerce як обов'язкову залежність. Перший курс безкоштовний; плагін іде на wp.org.

## Рішення
- LMS4WP працює без WooCommerce.
- Логіку продажу закладаємо, але вмикаємо лише за наявності WooCommerce і прив'язаного продукту.

## Наслідки
- Код WooCommerce-інтеграції — лише за `class_exists('WooCommerce')`.
- Замінює відповідний розділ `ARCHITECTURE.md`.
