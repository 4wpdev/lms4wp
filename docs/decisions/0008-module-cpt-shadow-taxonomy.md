# 0008. Модуль — CPT `lms_module` із тіньовою таксономією
Дата: 2026-11-14 · Статус: Прийнято · Замінює ADR 0004

## Контекст
Модулі жили лише в мета курсу (`_lms4wp_modules`) — у WordPress їх не можна створити, перейменувати чи перенести урок; курс існував тільки через імпорт з хабу. Курс має жити в WordPress сам по собі; хаб / Drive / CLI — лише способи наповнення.

## Рішення
1. **Модуль — CPT `lms_module`**: `post_parent` = курс, `menu_order` = порядок, заголовок, контент (опис з `requirements.md`), excerpt (мета модуля). Не публічний, у меню «Courses → Modules».
2. **Тіньова таксономія `lms_module_tax`** на уроках: один термін на кожен пост модуля, синхронізується автоматично (створення, перейменування, видалення). Вручну терміни не створюються — в уроці модуль лише обирається. Колонка «Module» і фільтр у списку уроків.
3. **`terminal.json` модуля** — у мета модуля `_lms4wp_terminal` (раніше — мета курсу).
4. **Хаб:** `requirements.md` має `type: module` і чисту назву модуля (`title: "Основи Git"`). Імпорт: тека модуля → пост модуля, урок → термін свого модуля.

## Наслідки
- Мета курсу `_lms4wp_modules` / `_lms4wp_terminals` і мета уроку `_lms4wp_module` більше не використовуються.
- Курс `git-basics` перестворено (`import --replace`): нові ID курсу, модулів і уроків.
- Модулі й прив'язку уроків можна редагувати в адмінці; для курсу з хабу наступний імпорт перезапише зміни (позначка «керується з хабу / з WordPress» — окреме рішення).
