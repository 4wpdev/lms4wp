# 0001. Хаб — джерело курсів, імпорт напряму через WP-CLI LMS4WP
Дата: 2026-11-14 · Статус: Замінено ADR-0005

## Контекст
Курси пишуться в `~/4wp-publish-hub/LMS4WP/courses/<slug>/`. 4wp-drive — інструмент контент-менеджерів; для курсів він не обов'язковий.

## Рішення
- Хаб — джерело істини. На сайті курс не редагується, а імпортується повторно.
- Імпорт — команда `wp lms4wp course import <path>` у LMS4WP, без 4wp-drive.
- Формат — `docs/COURSE-FORMAT.md`.

## Наслідки
- Повторний імпорт оновлює ті самі пости (зв'язок через `_lms4wp_source`).
- Ручні правки на сайті перезаписуються при імпорті.
