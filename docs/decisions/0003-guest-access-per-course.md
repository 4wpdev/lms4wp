# 0003. Доступ гостя задається в курсі
Дата: 2026-11-14 · Статус: Прийнято

## Контекст
Почати курс можна без авторизації; пройти — лише авторизованим (4wp-account). Боти не мають бачити весь курс.

## Рішення
- Що бачить гість (ознайомлення, скільки уроків відкрито) — налаштування конкретного курсу.
- Для проходження далі — авторизація.

## Наслідки
- Деталі налаштування — у SPEC F3–F5.
