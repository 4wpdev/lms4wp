# 0005. Git — джерело істини; пакет курсу імпортується повністю, правки — через 4wp-drive
Дата: 2026-11-14 · Статус: Прийнято · Замінює ADR 0001

## Контекст
ADR 0001 передбачав, що курс на сайті лише перезаписується повторним імпортом. Автор уточнив флоу: підготовлений курс заходить повністю, а дрібні виправлення йдуть через 4wp-drive.

## Рішення
1. **Пакет курсу** — тека `courses/<slug>/` у хабі `4wp-publish-hub`. Джерело істини — закомічений стан у git.
2. **Імпорт** — `wp lms4wp course import <path> --replace`: стирає курс і його уроки на сайті й створює заново. На курсі зберігається коміт хабу (`_lms4wp_source_commit`).
3. **Перевірка** — `wp lms4wp course verify <path>`: сайт = пакет (уроки, хеші, модулі, сироти, коміт).
4. **Правки** — зміна в git → 4wp-drive оновлює конкретний урок. Урок шукається за `_lms4wp_source`.
5. На сайті курс вручну не редагується.

## Наслідки
- `--replace` створює нові ID записів. Прогрес і записи на курс, прив'язані до старих ID, втрачаються — повний переімпорт лише до запуску курсу для студентів.
- 4wp-drive має підтримати оновлення `lms_lesson` за `_lms4wp_source` (поза цим репо, уточнити).
- Незакомічений пакет імпортується з попередженням і позначкою `-dirty` / `uncommitted`.
