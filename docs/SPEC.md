# Специфікація MVP: студентський флоу

Ціль: автор проходить флоу як студент на `https://4wpdev.local/` (див. `SITE-MAP.md`, схема 2).
Класичний LMS із практичними емуляторами. Без AI-оцінювання і реальних репозиторіїв.

## Обсяг

| # | Функція | Критерій готовності | Стан |
|---|---|---|---|
| F1 | Формат курсу | `COURSE-FORMAT.md` описує відповідність хаб → LMS4WP | готово |
| F2 | Імпорт і перевірка | `import --replace` створює курс, 7 модулів, 26 уроків; `verify` — без розбіжностей; повторний `import` — усе `skip` | готово в коді; запуск на локалі — за дозволом |
| F3 | Сторінка курсу | Опис, програма (модулі → уроки), блок ознайомлення; обсяг для гостя — налаштування курсу (ADR 0003) | готово: шаблон, блоки, «N уроків без входу» в кнопці |
| F4 | Старт без авторизації | Гість відкриває перші уроки за налаштуванням курсу; навігація попередній / наступний, модулі | готово: `guest_lessons` (front-matter / налаштування курсу), закритий урок → заглушка з входом, REST без контенту, noindex |
| F5 | Авторизація | Далі — через 4wp-account; після входу — запис на курс (`EnrollmentService`) | готово: вхід через 4wp-account (`/account/?redirect_to=`), «Join course» на уроці й курсі, повернення на урок; платний курс — лише покупка |
| F6 | Прогрес | «Урок пройдено», прогрес курсу | готово: «Mark as completed» → наступний урок, смуга прогресу, «Continue learning» → перший непройдений, позначки в програмі, завершення курсу |
| F7 | Q&A | Секція `Питання з інтерв'ю` → питання з відповіддю | — |
| F8 | Термінал | Секції `Команди` / `Практичне завдання` → емулятор 4wp-advanced-code | — |

Правки через 4wp-drive (ADR 0005) — окремий крок у 4wp-drive.

Поза MVP: WooCommerce-продаж (закладено, ADR 0002), AI-оцінювання, реальні репозиторії, FAQ → база знань, матеріали (пости, відео) з курсу.
